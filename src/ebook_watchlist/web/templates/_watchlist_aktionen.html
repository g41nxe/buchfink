{# Was man mit einem beobachteten Buch tun kann, als vier Zeichen (#22). Eine Stelle für Watchlist und Startseite: dieselbe Zeile soll überall dasselbe anbieten. Auf der Startseite fehlten die Zeichen ganz, während direkt darunter die Vorschlagszeilen welche trugen. Vier Zeichen statt eines Aufklappmenüs. Ein Menü verbirgt, was möglich ist, und niemand öffnet es, um nachzusehen. Wie ein solcher Knopf aussieht, steht in `_zeichenknopf.html` — derselbe wie auf der Vorschlagsseite, und die zwei ersten Zeichen stehen dort in derselben Reihenfolge. Zwei davon beenden den Eintrag und nehmen ihn aus der Liste. Bisher standen sie im Menü hinter einer Trennlinie; offen in der Zeile brauchen sie einen Weg zurück statt einer Nachfrage (ADR 30) — gelöscht wird nichts (ADR 18). `back` sagt, auf welcher Seite dieser Weg angeboten wird. Bei einem pausierten Eintrag wird aus ⏸ ein ▶. Nachsehen bleibt auch dort möglich: ein Lauf hängt nicht daran, ob der Eintrag ruht. #} {% from "_zeichenknopf.html" import zeichenknopf %} {% macro watchlist_aktionen(entry, closings, icons, back="/watchlist") %} {% for kind, label in closings %}

{% endfor %} {# Der enge Lauf tauscht die Zeile gegen sich selbst aus, wie das Menü es vorher tat (Ticket 51).
